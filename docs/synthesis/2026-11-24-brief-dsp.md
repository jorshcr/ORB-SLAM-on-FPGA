# BRIEF DSP mapping experiment - 2026-11-24

Explicit signed 6x8-bit rotation products with `use_dsp = "yes"` infer eight DSP48E1 blocks per BRIEF engine. Four-stage latency remains 259 clocks per descriptor; no extra pipeline stage was added. DSP inference absorbs some surrounding arithmetic/registers.

## Measured isolated BRIEF resources

Both variants use the same current BRIEF implementation, including output backpressure. The baseline was captured immediately before changing multiplication inference. Vivado 2024.1 synthesized and optimized both out of context for `xc7a100tcsg324-1`; these are **post-opt_design, not routed** counts. No clock constraint, placement, or timing analysis was used in this resource-only experiment.

| Resource | Baseline | DSP mapping | Change |
|---|---:|---:|---:|
| LUTs | 5,319 | 4,896 | -423 (-7.95%) |
| Registers | 8,687 | 8,529 | -158 |
| DSPs | 0 | 8 | +8 |
| BRAM tiles | 0 | 0 | 0 |

The substantial remaining LUT usage is consistent with the large variable-index pixel selection muxes and control logic, which this multiplier change does not remove. The resource reduction does not establish a timing improvement.

## Estimated ORB resources

Apply the measured per-engine delta to the last routed single-level ORB snapshot (20,017 LUTs, 30,736 registers, 11 BRAM tiles, 36 DSPs), with three BRIEF engines per level:

| Resource | One ORB level estimate | Three levels estimate | Three-level device utilization |
|---|---:|---:|---:|
| LUTs | 18,748 | 56,244 | 88.71% |
| Registers | 30,262 | 90,786 | 71.60% |
| BRAM tiles | 11 | 33 | 24.44% |
| DSPs | 60 | 180 | 75.00% |

These are estimates, mixing measured isolated post-optimization deltas with an older routed ORB baseline. They exclude newer result arbitration, the shared descriptor-output collector/FIFO, image scalers and integration overhead. The BRAM estimate assumes three identical 640x480 levels; smaller octaves can change line-buffer allocation. Three levels would still have limited LUT headroom and need complete synthesis/routing to establish fit and timing. The prior +0.305 ns setup result applies to the pre-DSP version only.
