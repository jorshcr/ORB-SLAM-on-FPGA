## Reproduce

Run from the repository root with the matching RTL revision:

```powershell
& 'C:/Xilinx/Vivado/2024.1/bin/vivado.bat' -mode batch -source orb_hardware/scripts/check_orb_timing.tcl -nojournal -log orb_timing.log
```

The script creates a timestamped directory under `orb_test_output/` and does not program the FPGA.
